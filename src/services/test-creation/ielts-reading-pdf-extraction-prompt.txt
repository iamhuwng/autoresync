## CRITICAL STRUCTURE RULES

1. Passages MUST start with exactly `READING PASSAGE 1`, `READING PASSAGE 2`, `READING PASSAGE 3` — this exact wording triggers passage detection.
2. If paragraphs have labels (A, B, C...), keep them: `A  paragraph text...` — these are referenced by matching-information questions.
3. Separate paragraphs with blank lines. NEVER merge into one block.
4. Include COMPLETE passage text — do not truncate or summarize.

## QUESTION FORMAT RULES

5. Each question sub-group starts with `Questions X-Y` on its own line, then the FULL instruction text, then the word limit if applicable.
6. Number every question: `1. text`, `2. text` etc.
7. MCQ options on ONE line: `A. opt1   B. opt2   C. opt3   D. opt4` (3 spaces between)
8. Completion blanks use 6+ underscores: `______`
9. Word limits on their own line: `Choose NO MORE THAN TWO WORDS from the passage for each answer.`
