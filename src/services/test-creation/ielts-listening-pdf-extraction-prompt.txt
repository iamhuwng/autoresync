## RULES

These rules are CRITICAL. The output will be machine-parsed and these exact patterns MUST be followed.

**Section headers**: Every question group MUST start on its own line with exactly `Questions X-Y` (e.g. `Questions 1-10`). This is the primary pattern the parser uses to detect sections. Separate groups with `---`.

**Instructions**: Place the FULL instruction text on the line(s) immediately after the `Questions X-Y` header. The parser detects question types from these keywords:
- "Complete the notes" → note-completion
- "Complete the form" → form-completion
- "Complete the table" → table-completion
- "Complete the sentences" → sentence-completion
- "Complete the summary" → summary-completion
- "Choose the correct letter" → multiple-choice
- "Choose TWO/THREE letters" → multiple-select
- "Label the map" → map-labelling
- "Label the plan" → plan-labelling
- "Label the diagram" → diagram-labeling
- "Match" / "which letter" → matching
- "Answer the questions" → short-answer
Keep these keywords EXACTLY as they appear in the original.

**Word limits**: ALWAYS put the word limit on its own separate line right after the instruction: `Write NO MORE THAN TWO WORDS AND/OR A NUMBER for each answer.`

**Blanks**: Use 6+ underscores `______` for fill-in blanks. For form/note completion, put the question number IMMEDIATELY before the blank: `1______` or `1 ______`.

**Form/Note completion**: Preserve the visual layout:
HEADING IN CAPS
Label: 1______
Another label: 2______

**Table completion**: Use pipe-separated format:
| Column A | Column B | Column C |
| Data | 3______ | Data |
| 4______ | Data | Data |

**MCQ options**: Put on separate lines starting with `A.`, `B.`, `C.`, `D.` — OR on one line with 3 spaces: `A. opt1   B. opt2   C. opt3`

**Matching options box**: List all options (A-H) BEFORE the numbered questions:
A. It has been enlarged.
B. It has been replaced.
C. It has been relocated.

21. entrance hall
22. main auditorium

**Numbered questions**: Format as `N. question text` — e.g. `16. The ceremony starts at ______.` The parser matches `^\d+[.)\s]+(.+)` to find questions.

**Answer key**: Each answer on its own line or compact: `1. Victoria  2. 742881`. Use / for alternatives: `22. 15/fifteen percent`. MCQ answers as letter only.
