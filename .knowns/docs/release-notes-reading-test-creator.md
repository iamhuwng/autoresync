# 🎉 New Feature: Automated IELTS Reading Test Creator

> Release Date: February 2026
> Version: 2.0

---

## What's New?

We're excited to introduce the **Automated IELTS Reading Test Creator** — a powerful new tool that helps you create complete Reading tests in minutes, not hours!

---

## ✨ Key Features

### 1. 📄 Smart Document Upload

**Upload your documents and let AI do the heavy lifting!**

- **Supported formats:** PDF, DOCX, TXT, or paste text directly
- **Automatic detection:** The system recognizes IELTS, TOEFL, and Cambridge formats
- **Drag & drop:** Simply drag your file into the upload area

---

### 2. 🤖 AI-Powered Parsing

**Our intelligent parser automatically extracts:**

- ✅ **Reading passages** with proper formatting
- ✅ **Question types** (Multiple Choice, True/False/Not Given, Matching, Completion, etc.)
- ✅ **Answer keys** when provided in the source document
- ✅ **Question numbering** (1-40 for standard IELTS)

**Confidence Scoring:** Each extracted element shows a confidence percentage so you know what needs review.

---

### 3. 👀 Easy Review & Edit

**Review everything before saving:**

| Feature | Description |
|---------|-------------|
| **🔍 Side-by-side comparison** | See original text next to parsed output |
| **⚠️ Uncertainty highlights** | Items needing attention are flagged |
| **✏️ Inline editing** | Click any field to edit |
| **📋 Checklist** | Complete all required items before saving |

---

### 4. 🔄 Resume Capability

**Never lose your work!**

If you close your browser or lose connection during parsing, simply:
1. Return to the Test Creator
2. Click "Resume Previous Session"
3. Continue from where you left off

---

## 📋 How to Use

### Step 1: Upload Your Document

1. Go to **Materials → Create New Test**
2. Select **Reading** as the skill
3. Upload your document or paste text

### Step 2: Let AI Parse

1. Watch the progress bar as sections are extracted
2. AI analyzes passages and questions
3. Validation checks run automatically

### Step 3: Review & Edit

1. Review each passage for accuracy
2. Check question types and answers
3. Address any flagged uncertainties
4. Complete the validation checklist

### Step 4: Save & Publish

1. Click **Save Test** when ready
2. Optionally publish immediately
3. Assign to students or classes

---

## 💡 Tips for Best Results

### ✅ DO:
- Use clear, well-formatted source documents
- Include answer keys in your source if available
- Review low-confidence items carefully
- Check passage word counts (aim for 750+ words each)

### ❌ DON'T:
- Upload scanned images (use OCR first)
- Mix multiple tests in one document
- Skip the review step
- Ignore validation warnings

## ❓ FAQ

### Q: What if the AI misses some questions?
**A:** You can manually add questions in the review screen. Click the "Add Question" button in any section.

### Q: Can I edit after saving?
**A:** Yes! Go to Materials, find your test, and click Edit. You can modify passages, questions, and answers anytime.

### Q: What question types are supported?
**A:** All standard IELTS Reading types:
- Multiple Choice
- True / False / Not Given
- Yes / No / Not Given
- Matching Headings
- Matching Information
- Matching Features
- Sentence Completion
- Summary Completion
- Diagram/Map Labeling
- Short Answer

### Q: Is there a document size limit?
**A:** Yes, documents should be under 10MB. For very long documents, consider splitting into sections.
