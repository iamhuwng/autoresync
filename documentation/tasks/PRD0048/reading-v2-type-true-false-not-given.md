Official slug: `true-false-not-given`

## Definition

Students judge statements using the locked vocabulary:

- True
- False
- Not Given

## Student Surface

- one shared instruction block
- one visible judgement vocabulary
- one statement per interaction

## TaskGroup Requirements

- explicit vocabulary lock
- ordered statement interactions
- passage linkage for reasoning context

## AnswerRule Essentials

- one judgement per interaction
- explicit vocabulary type

## Mobile Note

Keep the active statement and the TFNG vocabulary visible at the same time.

## Failure To Prevent

Do not normalize this into Yes / No / Not Given.
