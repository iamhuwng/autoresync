# Reading V2 Type: Summary Completion From List

Official slug: `summary-completion-list`
Engineering family: `choice`

Companion docs:

- `documentation/tasks/PRD0048/reading-v2-task-taxonomy-index.md`
- `documentation/tasks/PRD0048/reading-v2-family-choice.md`

## Definition

Students complete a summary shell by choosing answers from a visible option bank.

## Student Surface

- one summary block with multiple blanks
- one visible option bank
- one shared instruction block

## TaskGroup Requirements

- summary shell preserved as grouped structure
- explicit option-set reference
- blank order preserved

## AnswerRule Essentials

- selection mode from visible bank
- option label format when shown
- option reuse rule if the task requires it

## Mobile Note

Show the active blank with enough summary context and keep the option bank readable.

## Failure To Prevent

Do not misclassify this as free-text completion just because the visible shell looks similar to summary-from-text.
