# Reading V2 Type: Diagram Label Completion

Official slug: `diagram-labeling`
Engineering family: `structured-layout`

Companion docs:

- `documentation/tasks/PRD0048/reading-v2-task-taxonomy-index.md`
- `documentation/tasks/PRD0048/reading-v2-family-structured-layout.md`

## Definition

Students label anchored targets on a diagram, map, or similar image-based structure.

## Student Surface

- one diagram or image shell
- explicit target areas
- labels entered by typing or choosing from a set

## TaskGroup Requirements

- explicit hotspot anchors
- explicit label-source rule
- grouped instruction and answer rule

## AnswerRule Essentials

- input mode or label bank mode
- selection limit if label bank exists
- anchor binding requirement

## Mobile Note

Use zoomable image interaction with large target areas and a structured label-picking alternative.

## Failure To Prevent

Do not leave target identity implicit in image coordinates or UI-only overlays.
