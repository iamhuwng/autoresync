## Definition

Students assign items to a shared feature set such as names, categories, or groups.

## Student Surface

- one shared feature option set
- one target item per interaction
- one shared instruction block

## TaskGroup Requirements

- explicit feature option set
- explicit target item set
- explicit option reuse law

## AnswerRule Essentials

- one assignment per target
- option reuse allowed or disallowed

## Mobile Note

Use focused tap-to-assign with quick reassignment.

## Failure To Prevent

Do not assume reuse law. Store it explicitly.
