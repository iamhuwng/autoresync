# Reading V2 Type: Multiple Choice

Official slug: `multiple-choice`
Engineering family: `choice`

Companion docs:

- `documentation/tasks/PRD0048/reading-v2-task-taxonomy-index.md`
- `documentation/tasks/PRD0048/reading-v2-family-choice.md`

## Definition

Students choose one correct option from a visible option list.

## Student Surface

- one prompt per interaction
- one option list
- one correct choice

## TaskGroup Requirements

- explicit option set
- prompt text preserved
- single-select rule

## AnswerRule Essentials

- selection mode is single
- option label format if shown

## Mobile Note

Use clear single-select controls and preserve local prompt context.

## Failure To Prevent

Do not collapse labels or reorder options silently after publish.
