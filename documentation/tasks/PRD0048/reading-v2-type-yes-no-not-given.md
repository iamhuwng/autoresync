Official slug: `yes-no-not-given`

## Definition

Students judge claims or views using the locked vocabulary:

- Yes
- No
- Not Given

## Student Surface

- one shared instruction block
- one visible judgement vocabulary
- one statement or claim per interaction

## TaskGroup Requirements

- explicit vocabulary lock
- ordered statement interactions
- passage linkage for reasoning context

## AnswerRule Essentials

- one judgement per interaction
- explicit vocabulary type

## Mobile Note

Keep the active statement and the YNNG vocabulary visible at the same time.

## Failure To Prevent

Do not normalize this into True / False / Not Given.
