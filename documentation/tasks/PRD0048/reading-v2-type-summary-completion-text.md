# Reading V2 Type: Summary Completion From Text

Official slug: `summary-completion-text`
Engineering family: `completion`

Companion docs:

- `documentation/tasks/PRD0048/reading-v2-task-taxonomy-index.md`
- `documentation/tasks/PRD0048/reading-v2-family-completion.md`

## Definition

Students complete a shared summary shell using words from the passage, not from a visible option bank.

## Student Surface

- one summary block with multiple blanks
- one shared instruction block
- free-text entry for each blank

## TaskGroup Requirements

- summary shell preserved as grouped structure
- blank anchors or explicit blank order
- shared word-limit rule

## AnswerRule Essentials

- word limit
- source-of-answer expectation is from the passage
- explicit acceptable answer variants when needed

## Mobile Note

Keep summary shell context visible enough that the student knows which blank is active.

## Failure To Prevent

Do not convert the summary shell into unrelated sentence-completion cards.
