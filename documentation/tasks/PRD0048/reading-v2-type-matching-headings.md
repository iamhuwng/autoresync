# Reading V2 Type: Matching Headings

Official slug: `matching-headings`
Engineering family: `matching`

Companion docs:

- `documentation/tasks/PRD0048/reading-v2-task-taxonomy-index.md`
- `documentation/tasks/PRD0048/reading-v2-family-matching.md`

## Definition

Students assign headings to paragraphs or sections.

## Student Surface

- one heading list, often with roman numerals
- one paragraph or section target per interaction
- one shared instruction block

## TaskGroup Requirements

- explicit heading option set
- explicit paragraph or section targets
- reuse rule if the source material requires it

## AnswerRule Essentials

- option label format
- one assignment per target
- option reuse law

## Mobile Note

Use tap-to-assign, not drag-and-drop.

## Failure To Prevent

Do not lose paragraph identity or convert the group into flat isolated selects with no passage linkage.
