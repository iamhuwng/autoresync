# Reading V2 Type: Matching Information

Official slug: `matching-information`
Engineering family: `matching`

Companion docs:

- `documentation/tasks/PRD0048/reading-v2-task-taxonomy-index.md`
- `documentation/tasks/PRD0048/reading-v2-family-matching.md`

## Definition

Students assign statements or information items to paragraphs or sections in the passage.

## Student Surface

- one set of paragraph or section references
- one statement per interaction
- one shared instruction block

## TaskGroup Requirements

- explicit statement targets
- explicit paragraph reference set
- grouped passage linkage

## AnswerRule Essentials

- one assignment per target
- paragraph-reference vocabulary

## Mobile Note

Keep the active statement and paragraph choices readable in one focused answer layer.

## Failure To Prevent

Do not hide paragraph labels or force the student to remember them from another screen state.
