# Reading V2 Type: Matching Sentence Endings

Official slug: `matching-sentence-endings`
Engineering family: `matching`

Companion docs:

- `documentation/tasks/PRD0048/reading-v2-task-taxonomy-index.md`
- `documentation/tasks/PRD0048/reading-v2-family-matching.md`

## Definition

Students match sentence stems to one ending from a visible option set.

## Student Surface

- one list of sentence stems
- one list of ending options
- one shared instruction block

## TaskGroup Requirements

- explicit stem targets
- explicit ending option set
- explicit reuse law

## AnswerRule Essentials

- one ending per stem
- option reuse normally disallowed unless the material explicitly says otherwise

## Mobile Note

Keep the active stem visible while presenting ending options in a focused answer layer.

## Failure To Prevent

Do not reduce stems and endings into generic multiple-choice rows with no grouped sentence-pair logic.
