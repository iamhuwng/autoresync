# Reading V2 Type: Short Answer

Official slug: `short-answer`
Engineering family: `completion`

Companion docs:

- `documentation/tasks/PRD0048/reading-v2-task-taxonomy-index.md`
- `documentation/tasks/PRD0048/reading-v2-family-completion.md`

## Definition

Students answer direct prompts with short free-text responses drawn from passage understanding.

## Student Surface

- one direct prompt per interaction
- one free-text answer field
- one shared or local answer rule

## TaskGroup Requirements

- explicit prompt text per interaction
- explicit answer rule
- passage linkage for context

## AnswerRule Essentials

- word limit
- accepted answer variants
- number and punctuation policy

## Mobile Note

Use focused answer entry while preserving passage position.

## Failure To Prevent

Do not treat short-answer as a fully separate architecture when its scoring and editor behavior follow the completion family.
