# Reading V2 Type: Flowchart Completion

Official slug: `flowchart-completion`
Engineering family: `structured-layout`

Companion docs:

- `documentation/tasks/PRD0048/reading-v2-task-taxonomy-index.md`
- `documentation/tasks/PRD0048/reading-v2-family-structured-layout.md`

## Definition

Students complete a flowchart whose meaning depends on ordered steps and anchored blank positions.

## Student Surface

- one flowchart shell
- ordered blank targets
- shared instruction and answer rule

## TaskGroup Requirements

- explicit step order
- explicit step anchors
- grouped structure preserved

## AnswerRule Essentials

- word limit
- input mode
- anchor binding requirement

## Mobile Note

Use a simplified structural overview plus focused step-based answer entry.

## Failure To Prevent

Do not reduce the flow to detached sentences with no visible process order.
