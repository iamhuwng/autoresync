# Reading V2 Type: Note Completion

Official slug: `note-completion`
Engineering family: `completion`

Companion docs:

- `documentation/tasks/PRD0048/reading-v2-task-taxonomy-index.md`
- `documentation/tasks/PRD0048/reading-v2-family-completion.md`

## Definition

Students complete note-style lines or bullets using words from the passage.

## Student Surface

- note shell with blanks
- shared instruction block
- free-text entry

## TaskGroup Requirements

- preserve note hierarchy where it affects meaning
- ordered blank interactions
- grouped answer rule

## AnswerRule Essentials

- word limit
- accepted answer variants
- punctuation normalization when needed

## Mobile Note

Keep local note context visible in the answer layer.

## Failure To Prevent

Do not flatten indentation or bullet structure away if it changes comprehension.
