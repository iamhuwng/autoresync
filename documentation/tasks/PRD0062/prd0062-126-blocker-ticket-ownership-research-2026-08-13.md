# PRD0062 #126 blocker ownership research — 2026-08-13

## Finding

Issue [#126 / 50B](https://github.com/iamhuwng/autoresync/issues/126) is the
activation gate, not the owner of the three domain/tooling repairs below. It
must remain disabled until each upstream contract and its destination consumer
is repaired and proven. The PRD requires a single Book Delivery seam and says
that Book integrations use a frozen Placement binding, not a bare Activity ID
([§§23.1–23.2, lines 2461–2520](../../prd-book-based-interactive-activity-runtime-and-assembly.md#L2461-L2520)).
Component 07 repeats the contract in tasks 2.1–2.4
([task file](tasks-book-activity-07-cross-feature-delivery-results.md#L71-L76)).

1. **#30/#31:** add and validate `manifestVersionId` end-to-end in the immutable binding, v1/v2 compatibility path, persistence, current pointer, and negative/rules tests. Re-run #72 projection and #74 runtime-reader tests against a binding whose manifest, publication, Placement, Activity version, and rules claim all agree.
2. **#84/#85/#86/#59:** preserve the domain ownership split. Make #59's production factory explicitly construct the #84 authority, #85 saga, Delivery resolver, canonical Activity/Interaction resolver, and notification ports through environment-backed dependencies. Keep incomplete defaults fail-closed and prove Book requests never use `VITE_BACKUP_WORKER_URL`; run #86 route integration and #85 crash/replay/commit cases.
3. **#59/tooling:** repair or select an accepted Wrangler dependency context that installs the exact Cloudflare manifest/lock graph (including `jose`) and exposes it to live source resolution. Run both exact #126 configs, capture clean sidecars and protected-state hashes, and classify temporary external installs as diagnostics only.
4. **#126:** after the three upstream proofs, rerun the bounded activation evidence: registry truth, exact named identities, one teacher/≤30 students/one active assignment, positive PDF creation, non-allowlisted denial, readback, cleanup, and rollback. Keep all gates disabled until every prerequisite passes.
