## Rules

- Existing Book storage remains under `material_catalog`; PRD0062 extends it and must not create `ActivityBook`.
- Packet 1 Activity domain stores use RTDB under `book_activity/*`, rules in `database.rules.json`, and backup/restore inventory in `r2-backup-worker/src/backup/data-backup.ts` plus `r2-backup-worker/src/restore/restore-execute.ts`.
- Activity authoring records, source metadata, manifest data, placement bindings, and homework/update/runtime records must be reachable only through owning services.
- Student runtime reads only student-safe Book Delivery projections.
- Every new RTDB path, Firestore collection, R2/Worker path, index, backup target, and rule must get focused positive and negative tests before source-change packet closure.
- Local integration proof must exercise owning services, not direct fixture-only mutation.
